첫 번째 줄에 격자의 크기 $$N$$, $$M$$, 화살표의 개수 $$K$$가 공백으로 구분되어 주어진다. $$(2 \le N, M \le 200$$;
$$1 \le K \le \lfloor \frac{NM}{2} \rfloor)$$

두 번째 줄부터 $$K$$개의 줄에 걸쳐 화살표의 정보가 주어진다. 그중 $$i$$번째 줄에는 $$i$$번째 화살표에 대한 정보 $$r_i$$, $$c_i$$, $$l_i$$, 길이가 $$l_i$$인 문자열 $$D_i$$가 공백으로 구분되어 주어진다. $$(1 \le r_i \le N$$; $$1 \le c_i \le M$$; $$1 \le l_i < NM$$; $$D_{i, j} \in \{$$ `U` $$, $$ `D` $$, $$ `L` $$, $$ `R` $$\})$$

$$i$$번째 화살표의 길이는 $$l_i + 1$$이며 $$D_{i, j}$$는 $$j$$번째 격자점에서 $$j + 1$$번째 격자점을 바라보는 방향이다. 문자열의 문자는 `U`는 위, `D`는 아래, `L`은 왼쪽, `R`는 오른쪽을 의미한다. 행이 증가하는 방향이 아래, 열이 증가하는 방향이 오른쪽이다. 예를 들어 예제 입력 2의 2번째 화살표는 다음과 같이 이루어져 있다.

화살표가 자신과 겹치거나 한 격자점이 둘 이상의 화살표에 포함되거나 화살표가 격자 밖으로 벗어나는 경우는 입력으로 주어지지 않는다.
